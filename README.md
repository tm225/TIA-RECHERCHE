# Fouille

Application Android pour chercher un mot dans un fichier Excel, Word ou PowerPoint
et aller directement à la ligne concernée. Les fichiers ajoutés restent en mémoire
jusqu'à leur suppression.

## Obtenir l'APK
1. Poussez ce dépôt sur GitHub (branche `main`).
2. Ouvrez l'onglet **Actions** : la construction démarre toute seule (environ 5 minutes).
3. Téléchargez `Fouille.apk` dans l'onglet **Releases** (ou dans les artefacts de l'exécution).
4. Installez-le sur le téléphone (autoriser les sources inconnues).
